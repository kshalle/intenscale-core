# benchmarks/

A compute-intensive benchmark suite for the Intensivate core, assembled from
open-source applications and built to run bare metal on the target — no
operating system, under spike or the rocket-chip Verilator emulator.

Each workload also builds as a **static Linux binary**, from the same sources,
for cross-checking against a kernel and for running on RISC-V Linux hardware.
Both builds tag their own output, so a result always says which environment
produced it:

    make -C baremetal both                 # build every workload for both
    make -C baremetal run                  # bare metal, on spike
    make -C baremetal BM_ENV=linux run     # static Linux, under qemu-riscv64

    [bm] env=baremetal name=gcc-cc1 cycles=13214667 instret=13214672 ipc=1.000
    [bm] env=linux     name=gcc-cc1 counters=unrelated cputime_ms=111.221

Six workload classes, chosen to cover the machine behaviours that matter for a
general-purpose core:

| Directory | Workload | What it stresses | Licence |
|---|---|---|---|
| `compiler-gcc/` | C compiler (GCC 2.5.8 `cc1`) | irregular control flow, pointer chasing, large instruction footprint, heavy malloc | GPL-2.0-only |
| `interpreter-xlisp/` | Lisp interpreter (XLISP-PLUS) | deep recursion, cons-cell allocation, mark-and-sweep GC, poor locality | MIT |
| `interpreter-perl/` | Perl interpreter (Perl 4.036) | string and hash manipulation, regex compilation and matching, malloc churn | GPL-1.0-or-later OR Artistic-1.0 |
| `lattice-bsmbench/` | Lattice gauge theory (BSMBench) | SU(2) Monte Carlo, vectorisable double-precision stencils over a large working set | BSD-3-Clause + citation |
| `qchem-libcint/` | Quantum chemistry (libcint) | two-electron integral derivatives: long straight-line FP with extreme register pressure | Apache-2.0 |
| `weather-miniweather/` | Atmospheric dynamics (miniWeather) | dense double-precision stencil over a compressible flow field | BSD-2-Clause |

`baremetal/` holds the ports of these that run on the core with no OS, and the
Linux build of the same ports.  Start with
[`baremetal/README.md`](baremetal/README.md) for the harness, the two
environments, and what the Linux build's numbers do and do not mean; then
[`baremetal/PORT-STATUS.md`](baremetal/PORT-STATUS.md) for what is verified
where.

Each application directory carries an `ORIGIN.md` recording the exact upstream
release, its licence, why it was chosen for its workload class, and any local
modifications (there are none beyond removing version-control metadata).

## Licensing

Work by Intensivate is **BSD-2-Clause**; each vendored upstream keeps its own
licence.  A permissive licence is deliberate — the suite links our harness
with GPL programs, and a GPL-incompatible licence would make the built
binaries non-redistributable.

- [`LICENSE`](LICENSE) — the short version
- [`LICENSE-AUDIT.md`](LICENSE-AUDIT.md) — file-by-file position, third-party
  notices found inside the upstream trees, what is still open for counsel
- [`NOTICE.md`](NOTICE.md) — attributions, and **BSMBench's citation
  requirement**, which attaches to any published figure from that port
- [`LICENSES/`](LICENSES/) — verbatim texts; [`REUSE.toml`](REUSE.toml) —
  declarations for files that cannot carry a header
- [`PROVENANCE.md`](PROVENANCE.md) — where each application came from and what
  obligations travel with it

## Workloads

Every workload driven by these benchmarks — the Lisp and Perl scripts, the
lattice input decks, the quantum-chemistry basis, the C translation units fed
to the compiler — was written for this suite or is generated by scripts in it.
None is taken from any third-party benchmark suite.

Only upstream source is vendored.  `.git/`, `.github/` and CVS metadata were
removed, and three trims were made to keep the release small: nine Rys-root
data tables in `qchem-libcint/` that nothing here compiles, and four
documentation binaries in `weather-miniweather/` and `interpreter-xlisp/`.
**No source file was altered.**  Each is recorded, with checksums for
restoring it from upstream, in the relevant `ORIGIN.md`.  Build products and generated files are
`.gitignore`d.
